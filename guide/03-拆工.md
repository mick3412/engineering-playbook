# 3 拆工

拆成小步驟，每一步都能單獨驗證；能平行的就平行。

**這一步要產出：** 步驟清單

## 要做

- [ ] **3.1 拆小步驟**：每一步小到能在一次對話內完成並驗證
- [ ] **3.2 平行與分工**：標出彼此獨立的步驟，交給子 agent 或另一個工作階段
  - 外派的判斷：能用程式或抽查驗證的批次工作才外派，主線只驗證（S3-01，待試）
  - 派任務寫交接單；審查只回 PASS 或 FAIL，重試 3 次不過就停下回報（S3-02，待試）
- [ ] **3.3 檔案不重疊**：平行的步驟不碰同一批檔案；會重疊的就排先後
