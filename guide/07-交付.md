# 7 交付

小步交付，讓人看得懂改了什麼、出事時退得回去。

**這一步要產出：** commit、PR 或發佈紀錄

## 要做

- [ ] **7.1 commit 與 PR**：PR 拆小、一個 PR 只做一件事；說明寫清楚改了什麼、怎麼驗證
  - PR 拆小、每個 PR 只做一件事（S7-01）
- [ ] **7.2 上線檢查**：推送、合併、上線前由人核准；照清單檢查
  - 幾種做法：(a) engineering:deploy-checklist 技能
  - 檢查：agent 上線前：先跑影子模式，再開有限的真實動作（S7-03，待試）
  - 改不回來的動作先存成提案，核准後才執行並回頭確認；無人值守的 agent 要有花費上限和外部的停止開關（S7-04，待試）
- [ ] **7.3 監控**：上線後看錯誤和關鍵指標；寫好怎麼退回

## 用什麼工具

- **GitHub CLI（gh）**（T-39）：在終端機開 PR、看 CI、發 release、管 issue 時

## 要注意

- 推送、上線、對外發送一律等人明確同意（S7-02）
