## 摘要（以自己的話整理）

- auto：可還原的內部步驟（本機檔案、本機 commit、worktree、測試、已授權的動作）不問，決定後記錄並繼續；硬停止（對外訊息、安裝或 clone、密鑰、不可復原刪除、付款、權限、正式環境）列待辦；所有會跳確認的動作排最後連續執行；待辦在結尾一次報告並附建議。gate 拒絕時照理由改正重試。
- out：能用檢查程式或抽查驗證的批次工作交給便宜模型的背景子代理或外部 CLI；可測試的修正與挑錯審查可交第二模型；判斷與快完成的工作留主線；主線讀大量原始輸出未外派時提醒一次。
- wrap：不開新方向；待決事項放最後一節，只列新的或有變動的，每項帶標籤（對外、付款、刪除、權限、取捨）並附建議；取捨須寫出各自好處；無標籤者自己做；全部完成即一句話結束。
- gates：auto 下把「詢問」改成「附替代做法的拒絕」：新建報告類 md、帶路徑的 git commit／會夾帶未暫存修改的 git add、待決事項沒標籤。硬停止不放進 gates。
- 模式文字只在切換後與壓縮／恢復後送一次，不每輪重複。
